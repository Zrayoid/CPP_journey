# C++ Journey

**Learning C++ through practice, problem-solving, and understanding how things work under the hood.**

This repository documents my journey of learning C++ from the fundamentals toward deeper programming concepts, memory management, and software development.

Rather than just collecting code, I’m using this journey to strengthen my logic, understand how programs work, and build a solid foundation for my long-term goal: **game development**.

## 🎯 Goals

- Build a strong foundation in modern C++
- Improve problem-solving and logical thinking
- Understand memory, pointers, and data structures
- Write clean, understandable, and efficient code
- Gradually move from basic exercises to larger projects

## 📚 Topics

| Topic | Focus |
|---|---|
| Variables | Storing and working with data |
| Data Types | Understanding different kinds of values |
| Conditions | Making decisions in programs |
| Loops | Repeating operations and solving iterative problems |
| Functions | Breaking programs into reusable parts |
| Bitwise Operators | Working with individual bits and bit manipulation |
| Arrays | Storing, accessing, and manipulating collections of data |

More topics will be added as I progress through C++.

## 🧠 How I Learn

My approach is simple:

1. Understand the concept.
2. Practise with programming problems.
3. Review mistakes and improve the solution.
4. Apply the concept in more complex programs.
5. Keep building toward projects and real-world programming.
